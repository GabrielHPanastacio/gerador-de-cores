# 🎨 Gerador de Cores

Aplicação simples que gera cores aleatórias ao clicar em um botão, alterando o fundo da página e exibindo o código HEX.

## Funcionalidades

- Gera uma cor HEX aleatória a cada clique
- Atualiza o fundo da página com transição suave
- Exibe o código da cor na tela

## Tecnologias

- HTML5 semântico
- CSS3 (Flexbox)
- JavaScript (DOM e eventos)

## Como executar

```bash
git clone https://github.com/GabrielHPanastacio/gerador-de-cores.git
cd gerador-de-cores
open index.html
```

## Estrutura

```
gerador-de-cores/
├── index.html
├── style.css
└── script.js
```

## Aprendizados

- Manipulação do DOM com `getElementById` e `addEventListener`
- Geração de valores aleatórios com `Math.random()`
- Centralização de layout com Flexbox
